概要
このプロジェクトは、Vue 3 + TypeScript を使用して開発された DECO27 の紹介ウェブサイトです。ミュージシャンである DECO27 に関する情報を表示し、その音楽活動の軌跡を紹介します。Vue 3 の Composition API を活用し、TypeScript による型安全なコード構成を実現しています。

主な使用技術
フロントエンド：Vue 3、TypeScript、Vue Router、Vite、CSS
ホスティング：AWS EC2、Nginx
その他：Git、ESLint、Prettier
機能一覧
ホームページ表示 ：DECO27 の基本情報と主要ナビゲーションを提供
紹介ページ ：タイムライン機能を通じて DECO27 の活動年表を視覚的に紹介
ソーシャルメディアリンク ：各種 SNS アカウントへのアクセスを提供
ページナビゲーション ：ウェブサイト内の各ページを簡単に移動できるナビゲーション機能
画像リソース管理 ：パフォーマンス最適化を考慮した画像の読み込みと表示
